Digital Twin for the UAV Airframe and Engine

Digital Twin for the Aero-Piston Engine

This module creates a real-time virtual replica of the engine, fusing simulated sensor data with a physics-based expected-state model to track deviation, subsystem health, and overall engine condition.

It supports the mission's Engine Health Monitoring goal by continuously watching RPM, temperatures, pressures, and vibration, flagging early-stage anomalies before they progress to mission-critical faults, and estimating remaining useful life for key degradation modes.

Engineering Components Behind the Digital Twin

Physics-Based Engine Simulator

Generates synchronized telemetry for RPM, CHT, EGT, oil pressure, fuel flow, and vibration once per second. Includes configurable mission profiles, altitude, and thermal environment models.

Digital Twin Core

Computes expected operating values and subsystem health indices from live telemetry deviation. Tracks combustion, thermal, lubrication, mechanical, and electrical subsystem states.

AI/ML Predictive Analytics

Isolation Forest anomaly detection, Random Forest/XGBoost fault classification, and regression-based RUL estimation. SHAP feature attribution explains each diagnostic decision.

FastAPI + PostgreSQL Backend

REST services with Pydantic validation and a WebSocket stream push fresh twin state to the dashboard. Mission lifecycle and telemetry persistence handled by PostgreSQL.

React GCS-Style Dashboard

Nine operator pages covering live monitoring, twin health, predictive health, alerts, and mission replay. Connected via REST and WebSocket for real-time data flow.

Alert & Maintenance Engine

Rule-based advisories combining fault type, severity, trend, and RUL into actionable recommendations. Alerts fire once per state transition, never duplicated per tick.
